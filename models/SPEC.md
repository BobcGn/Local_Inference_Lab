# 模型身份与本地资产

## 职责

记录模型来源、不可变 revision、文件集合、量化和校验身份，使实验能够区分“同名模型”与“同一份权重”。具体下载命令与已知校验值只维护在本目录 README。

MLX 快照是权重分片、索引、配置、分词器与模板组成的整体；单独复制权重不代表完整可运行模型。GGUF 对照至少核对指定文件的大小与 SHA-256，不能只比较文件名。

## 边界

模型文件和下载缓存只保存在本地，不提交到总仓库。模型来源的访问条件与许可独立于本仓库；记录来源不等于获得再分发授权。

模型格式和 MoE 标签不保证运行时兼容；架构、算子、量化与专家布局必须以所选运行时实际支持为准。新增模型需给出身份和研究用途，尚未选择的小模型不编造 revision。

## 当前事实

维护者报告已下载模型，但没有在本次文档工作中执行文件校验或加载。下载成功、文件完整、运行时可加载、输出正确是分别验证的事项。
