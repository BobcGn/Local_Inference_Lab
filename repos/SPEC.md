# 第三方源码与修改溯源

## 职责

维护外部运行时的来源和版本身份，使实验结果可关联到真实执行的实现，而非变化中的默认分支。固定版本与准备命令只维护在本目录 README。

每次运行记录远端、完整 commit SHA、工作区是否有修改及构建选项。存在修改时，提供可访问提交或可复现补丁和基准提交；仅给出本地分支名不足以复现。

## 边界

各上游保留独立 Git 历史，源码检出和构建产物不加入总仓库，也不在没有明确迁移决策时转成 submodule 或 vendor。研究说明与版本元数据可以提交总仓库。

上游文档、提案、移动分支或演示只能证明其描述的范围，不能证明目标平台可运行。读取某版本源码与在该版本实际运行是不同验证状态。第三方修改和再分发遵循各自许可；本仓库不替上游作授权承诺。
