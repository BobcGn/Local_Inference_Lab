# 实验自动化约束

## 职责与现状

承载下载、构建、运行和结果整理的自动化；当前仅有目录占位，没有实现、统一 CLI 或可执行的测量工具。本规格约束新增自动化，不声明已有接口。

## 自动化边界

以下是基于可复现实验目标推断的自动化约束（未确认，待维护者审阅）。脚本是可审查手动步骤的封装，不隐藏或改变模型 revision、运行时版本、实际后端、输入及测量口径。调用者必须能看到有效参数、输出位置、失败原因及可用于复现的命令或日志。

新增脚本显式说明工作目录、平台、依赖和副作用。下载、更新检出、覆盖记录、清理缓存和大内存运行不能作为未说明的隐式动作；已有模型与结果不应被无提示覆盖。失败必须可识别，不能以成功记录替代部分失败。

## 资源与实现自由

不预先规定语言或参数名。只在确有重复操作时加入脚本，并附对应运行示例及验证方式。目标平台没有实际测试时标记未验证，不把 macOS 的执行结果宣传为 Windows 也适用。
