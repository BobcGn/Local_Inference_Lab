# 决策检索与历史

本目录只提供决策位置与历史修订的检索，不是第二套决策正文。持久决策、适用边界及其理由归对应 owning spec，分工见 [文档 SPEC](../SPEC.md)；当前有效内容以规格为准。

规格的 draft 状态不因被本索引引用而变成已审阅或已验证。返回 [文档导航](../README.md)。

## 如何新增历史条目

只有确有可追溯的规格修订时才新增条目。输入是 owning spec、真实历史提交及关联资料／证据；输出是便于找到该决策的短索引。不要在这里复制取舍、理由或另写相互竞争的结论。当前尚无历史条目，以下仅为结构示例：

~~~markdown
# <主题 · 历史索引>
- 日期：YYYY-MM-DD
- 索引状态：当前指向／历史／已被替代
- owning spec：相对链接与章节
- 来源版本：总仓库完整 commit SHA、当时的规格路径与章节
- 修订线索：变更前／后真实提交；仅待提交时写“未提交”，不编造 SHA
- 验证状态：仅规格修订／待验证／已有关联运行证据
- 历史资料：来源 URL、版本、访问日期（无则写无）
- 证据入口：运行记录链接或“无运行证据”
- 后继入口：替代它的 owning spec 位置；无则写无
~~~

索引状态与运行验证状态分别维护；修改索引前先核对 owning spec。需要说明“为什么”时链接该规格相应章节或真实历史版本，不在此重述。只链接现有文件或可访问的真实版本，分享前检查敏感信息及引用权限。
