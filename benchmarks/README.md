# 基准测量口径

每次运行从 [运行记录模板](run-template.md) 开始。先固定模型与权重版本、运行时、实际后端、提示词及聊天模板、采样、上下文、批大小、并发和生成上限。每组预热一次后至少重复三次，保留逐次值和中位数，并记录实际 token 数和缓存状态。

| 指标 | 测量口径 |
| --- | --- |
| 模型加载耗时 | 从运行时开始加载到模型可处理请求。若权重存在惰性加载，注明首次请求是否包含相应开销。 |
| TTFT | 从已加载模型开始处理请求，到首个 token 可用的时间。只有文本流时，记录首个文本块延迟。MLX 自定义计时以实际求值或同步完成为准。 |
| Prefill tok/s | 输入 token 数除以 prefill 耗时，或使用框架原始值并注明定义。 |
| Decode tok/s | 自定义逐 token 测量用首末 token 间隔和 `N−1` 个 token，`N < 2` 记为未测。框架原始值保留来源与定义。 |
| 内存 | 分别记录进程峰值 RSS、运行时分配器峰值，以及系统内存压力和交换量。为每项注明单位和采样方法。 |
| 权重读取 | 分别记录应用层读量和设备层读量。`pread` 返回的字节可能由文件页缓存提供，进程重启也可能保留文件页缓存。 |
| 输出一致性 | 同权重、同模板、同采样下比较 token ID，记录首个差异。只能取得文本时，注明对照粒度。 |

`memory/`、`throughput/`、`correctness/` 保存对应的汇总和可分享证据。临时和体积较大的原始产物可存放在本地 `benchmarks/local/`。
