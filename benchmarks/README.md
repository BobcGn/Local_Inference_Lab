# 基准测量口径

本目录保存运行记录、逐次结果与可分享证据。目前没有已提交的实测结果或自动测量工具。指标定义、计时边界、统计与正确性要求统一见 [测量契约](SPEC.md)，此处只说明如何组织和提交结果。

## 记录一次运行

1. 复制 [运行记录模板](run-template.md)，建议保存到 `runs/<run-id>.md`，运行 ID 包含日期、实验号、平台和条件；目录不存在时按需创建。
2. 填写总仓库提交、模型与运行时身份、实际后端、完整命令及测量工具。不要只记录默认参数或模型名称。
3. 完成模板中的逐次结果与证据链接；未测项写“未测 + 原因”，失败项保存错误，不用空白或零代替。
4. 只在证据支持时更新实验状态与汇总；正式测量和首次生成检查分别标记。

## 文件组织

- `runs/<run-id>.md`：推荐的单次实验记录入口，`runs/<run-id>/` 保存相关小型日志与输出；这两类路径按需创建。
- `memory/`、`throughput/`、`correctness/`：按主题汇总并链接运行记录，不复制或丢弃逐次证据。当前仅有占位目录。
- `local/`：被 Git 忽略的大文件和临时数据，不是协作者可访问的共享证据。

同一条件重跑使用新运行 ID 或明确标记追加批次，不覆盖旧记录。Windows 和 macOS 数据分别注明机器，不能把跨机差异当作后端差异；比较前查看 [架构边界](../architecture.md)。

## 分享前

按 [贡献指南](../CONTRIBUTING.md) 检查脱敏、文件体积和可复现性。需要人工检查输出时参考 [固定输入说明](../experiments/01-mlx-baseline/prompts/README.md)。模板不代表每项工具已经可用：没有仪表或无法取得 token ID 时明确说明，只对实际取得的证据下结论。
